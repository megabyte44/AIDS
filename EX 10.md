
# Simple Guide: F-test and One-Way ANOVA

Three basic statistics concepts, kept simple: the idea, step-by-step procedure, short pseudocode, and a small working Python example for each.

---

## 10. Demonstrating F-test

### Concept
An F-test compares the **variances** (spread) of two populations. It asks: "Is one group significantly more spread out than the other?" It assumes both populations are approximately normal.

- **Null hypothesis (H0):** variance 1 = variance 2
- **Alternative hypothesis (H1):** variance 1 != variance 2
- If the p-value is less than the significance level (usually 0.05), reject H0.

Formula: `F = s1^2 / s2^2` with degrees of freedom `df1 = n1 - 1` and `df2 = n2 - 1`

### Procedure
1. State H0 (variances are equal) and H1 (variances differ).
2. Choose the significance level alpha (e.g. 0.05).
3. Compute the sample variance of each group (divide by n - 1).
4. Compute `F = s1^2 / s2^2`.
5. Find the degrees of freedom: `df1 = n1 - 1`, `df2 = n2 - 1`.
6. Find the p-value from the F-distribution (two-tailed: `2 * min(cdf, 1 - cdf)`).
7. If p-value < alpha, reject H0; otherwise fail to reject H0.

### Pseudocode
```
F-TEST(sample1, sample2, alpha):
    n1, n2 <- size of sample1, size of sample2
    var1 <- sample variance of sample1 (divide by n1 - 1)
    var2 <- sample variance of sample2 (divide by n2 - 1)
    F <- var1 / var2
    df1 <- n1 - 1
    df2 <- n2 - 1
    p_value <- 2 * min(f_cdf(F, df1, df2), 1 - f_cdf(F, df1, df2))   # two-tailed
    if p_value < alpha:
        return "Reject H0 (variances differ)"
    else:
        return "Fail to reject H0 (variances are equal)"
```

### Python Implementation
```python
import numpy as np
from scipy import stats      # pip install numpy scipy

# Two machines fill bottles. Is one machine less consistent than the other?
machine_a = [85, 88, 90, 86, 87, 89, 91, 84]
machine_b = [78, 95, 70, 99, 82, 92, 75, 97]

alpha = 0.05   # significance level

def f_test(sample1, sample2):
    var1 = np.var(sample1, ddof=1)   # sample variance (n - 1)
    var2 = np.var(sample2, ddof=1)
    F = var1 / var2
    df1 = len(sample1) - 1
    df2 = len(sample2) - 1
    # two-tailed p-value
    p_value = 2 * min(stats.f.cdf(F, df1, df2), stats.f.sf(F, df1, df2))
    return var1, var2, F, df1, df2, p_value

var1, var2, F, df1, df2, p_value = f_test(machine_a, machine_b)

print("Variance (A)       :", round(var1, 4))
print("Variance (B)       :", round(var2, 4))
print("F statistic        :", round(F, 4))
print("Degrees of freedom :", (df1, df2))
print("P-value            :", round(p_value, 4))

if p_value < alpha:
    print("Result: Reject H0 (variances differ)")
else:
    print("Result: Fail to reject H0 (variances are equal)")
```

**Output:** F = 0.0486, p-value = 0.0007, so H0 is rejected. Machine B is much less consistent than machine A.

## 11. Demonstrating One-Way ANOVA

### Concept
One-way ANOVA (Analysis of Variance) checks whether the **means of three or more groups** are all equal. Running many separate t-tests inflates the chance of a false positive, so ANOVA tests all groups at once using an F-test.

The idea: compare the variation **between** groups with the variation **within** groups. If the group means are far apart compared with the natural spread inside each group, F becomes large.

- **Null hypothesis (H0):** all group means are equal (mu1 = mu2 = ... = muk)
- **Alternative hypothesis (H1):** at least one group mean is different
- If the p-value is less than alpha, reject H0.

**Assumptions:** groups are independent, data in each group is roughly normal, and the groups have similar variances.

### Formulas
| Quantity | Formula |
|---|---|
| Grand mean | `mean of all N observations` |
| Sum of squares between (SSB) | `sum of n_i * (group_mean_i - grand_mean)^2` |
| Sum of squares within (SSW) | `sum of (x - group_mean_i)^2 over all observations` |
| df between | `k - 1` |
| df within | `N - k` |
| Mean square between (MSB) | `SSB / (k - 1)` |
| Mean square within (MSW) | `SSW / (N - k)` |
| F statistic | `F = MSB / MSW` |

(k = number of groups, N = total number of observations)

### Procedure
1. State H0 (all means equal) and H1 (at least one mean differs).
2. Choose the significance level alpha (e.g. 0.05).
3. Compute each group's mean and the grand mean.
4. Compute SSB (variation between group means and the grand mean).
5. Compute SSW (variation of values around their own group mean).
6. Compute degrees of freedom: `df_between = k - 1`, `df_within = N - k`.
7. Compute `MSB = SSB / df_between` and `MSW = SSW / df_within`.
8. Compute `F = MSB / MSW`.
9. Find the p-value from the F-distribution (right tail only): `p = 1 - f_cdf(F, df_between, df_within)`.
10. If p-value < alpha, reject H0; otherwise fail to reject H0.

### Pseudocode
```
ONE-WAY-ANOVA(groups, alpha):
    k <- number of groups
    N <- total number of observations
    grand_mean <- average of all observations

    SSB <- 0
    SSW <- 0
    for each group in groups:
        group_mean <- average of group
        SSB <- SSB + size(group) * (group_mean - grand_mean)^2
        for each x in group:
            SSW <- SSW + (x - group_mean)^2

    df_between <- k - 1
    df_within  <- N - k
    MSB <- SSB / df_between
    MSW <- SSW / df_within
    F <- MSB / MSW
    p_value <- 1 - f_cdf(F, df_between, df_within)     # right-tailed

    if p_value < alpha:
        return "Reject H0 (at least one mean differs)"
    else:
        return "Fail to reject H0 (no significant difference in means)"
```

### Python Implementation
```python
from scipy import stats      # pip install scipy

# Exam scores of students taught by 3 different methods (10 students each)
method_a = [85, 86, 88, 75, 78, 94, 98, 79, 71, 80]
method_b = [91, 92, 93, 85, 87, 84, 82, 88, 95, 96]
method_c = [79, 78, 88, 94, 92, 85, 83, 85, 82, 81]

groups = [method_a, method_b, method_c]
alpha = 0.05   # significance level

def one_way_anova(groups):
    k = len(groups)                              # number of groups
    N = sum(len(g) for g in groups)              # total observations
    grand_mean = sum(sum(g) for g in groups) / N

    ssb = 0   # sum of squares between groups
    ssw = 0   # sum of squares within groups
    for g in groups:
        group_mean = sum(g) / len(g)
        ssb += len(g) * (group_mean - grand_mean) ** 2
        ssw += sum((x - group_mean) ** 2 for x in g)

    df_between = k - 1
    df_within = N - k
    msb = ssb / df_between
    msw = ssw / df_within
    F = msb / msw
    p_value = stats.f.sf(F, df_between, df_within)   # right-tailed
    return grand_mean, ssb, ssw, df_between, df_within, msb, msw, F, p_value

(grand_mean, ssb, ssw, df_b, df_w,
 msb, msw, F, p_value) = one_way_anova(groups)

print("Grand mean            :", round(grand_mean, 2))
print("SSB (between)         :", round(ssb, 2))
print("SSW (within)          :", round(ssw, 2))
print("df (between, within)  :", (df_b, df_w))
print("MSB                   :", round(msb, 4))
print("MSW                   :", round(msw, 4))
print("F statistic           :", round(F, 4))
print("P-value               :", round(p_value, 4))

if p_value < alpha:
    print("Result: Reject H0 (at least one mean differs)")
else:
    print("Result: Fail to reject H0 (no significant difference in means)")

# Cross-check with SciPy's built-in function
print("SciPy check:", stats.f_oneway(method_a, method_b, method_c))
```

**Output:** group means are 83.4, 89.3 and 84.7; F = 2.3575, p-value = 0.1138. Since p > 0.05, we fail to reject H0: there is no significant evidence that the teaching methods give different average scores.

> If H0 is rejected, ANOVA only says that *some* mean differs. A post-hoc test (e.g. Tukey's HSD) is then used to find which groups differ.

## 12. Demonstrating Two-Way ANOVA

### Concept
Two-way ANOVA studies the effect of **two factors** on one measured outcome at the same time. It answers three questions with three F-tests:

1. Does **Factor A** affect the outcome? (main effect of A)
2. Does **Factor B** affect the outcome? (main effect of B)
3. Do A and B **interact**? That is, does the effect of one factor depend on the level of the other? (interaction A x B)

Hypotheses (each tested separately):

- **H0 (A):** all levels of A have the same mean. **H0 (B):** all levels of B have the same mean. **H0 (A x B):** there is no interaction.
- **H1:** the corresponding effect exists.
- If a p-value is less than alpha, reject that H0.

**Assumptions:** independent observations, roughly normal data, equal variances, and (for the simple formulas below) a balanced design with the same number of replicates `n` in every cell.

### Formulas
a = levels of A, b = levels of B, n = replicates per cell, N = a*b*n

| Source | Sum of squares | df | Mean square | F |
|---|---|---|---|---|
| Factor A | `SSA = b*n * sum(meanA_i - GM)^2` | `a - 1` | `MSA = SSA / (a-1)` | `MSA / MSE` |
| Factor B | `SSB = a*n * sum(meanB_j - GM)^2` | `b - 1` | `MSB = SSB / (b-1)` | `MSB / MSE` |
| Interaction A x B | `SSAB = n * sum(cell_ij - meanA_i - meanB_j + GM)^2` | `(a-1)(b-1)` | `MSAB = SSAB / df` | `MSAB / MSE` |
| Error (within) | `SSE = sum(x - cell_mean)^2` | `a*b*(n-1)` | `MSE = SSE / df` | |

(GM = grand mean, meanA_i = mean of all values at level i of A, meanB_j = mean of all values at level j of B, cell_ij = mean of the cell for A level i and B level j)

### Procedure
1. State the three pairs of hypotheses (A, B, interaction) and choose alpha (e.g. 0.05).
2. Arrange the data in a table of cells (each combination of A level and B level), with n values per cell.
3. Compute the grand mean, the mean of each A level, the mean of each B level, and the mean of each cell.
4. Compute SSA, SSB, SSAB and SSE using the formulas above.
5. Compute the degrees of freedom: `a-1`, `b-1`, `(a-1)(b-1)`, `ab(n-1)`.
6. Compute each mean square: `MS = SS / df`.
7. Compute the three F values: `F = MS(effect) / MSE`.
8. Find each p-value from the F-distribution (right tail) using that effect's df and the error df.
9. Compare each p-value with alpha and decide for A, B and the interaction separately.
10. If the interaction is significant, interpret the main effects with care, because the effect of one factor changes with the other.

### Pseudocode
```
TWO-WAY-ANOVA(data[i][j] = list of n values, alpha):
    a <- number of levels of A
    b <- number of levels of B
    n <- values per cell
    grand_mean <- average of all values
    meanA[i]   <- average of all values at level i of A
    meanB[j]   <- average of all values at level j of B
    cell[i][j] <- average of data[i][j]

    SSA  <- b * n * sum over i of (meanA[i] - grand_mean)^2
    SSB  <- a * n * sum over j of (meanB[j] - grand_mean)^2
    SSAB <- n * sum over i,j of (cell[i][j] - meanA[i] - meanB[j] + grand_mean)^2
    SSE  <- sum over i,j and each x in data[i][j] of (x - cell[i][j])^2

    dfA <- a - 1;  dfB <- b - 1;  dfAB <- (a-1)*(b-1);  dfE <- a*b*(n-1)
    MSE <- SSE / dfE

    for each effect in (A, B, AB):
        F <- (SS_effect / df_effect) / MSE
        p_value <- 1 - f_cdf(F, df_effect, dfE)           # right-tailed
        if p_value < alpha:
            report "Reject H0: effect is significant"
        else:
            report "Fail to reject H0: effect is not significant"
```

### Python Implementation
```python
from scipy import stats      # pip install scipy

# Plant growth (cm) for 3 fertilizers (Factor A) x 2 sunlight levels (Factor B),
# with 5 plants in every cell.
data = {
    ("Fert 1", "Low sun"):  [6, 7, 6, 8, 7],
    ("Fert 1", "High sun"): [9, 10, 8, 9, 10],
    ("Fert 2", "Low sun"):  [8, 9, 8, 10, 9],
    ("Fert 2", "High sun"): [14, 13, 15, 14, 12],
    ("Fert 3", "Low sun"):  [7, 6, 8, 7, 6],
    ("Fert 3", "High sun"): [10, 11, 9, 10, 12],
}
alpha = 0.05   # significance level

def mean(x):
    return sum(x) / len(x)

def two_way_anova(data):
    A_levels = sorted({key[0] for key in data})
    B_levels = sorted({key[1] for key in data})
    a, b = len(A_levels), len(B_levels)
    n = len(next(iter(data.values())))           # replicates per cell

    grand_mean = mean([x for v in data.values() for x in v])
    mean_A = {i: mean([x for j in B_levels for x in data[(i, j)]]) for i in A_levels}
    mean_B = {j: mean([x for i in A_levels for x in data[(i, j)]]) for j in B_levels}
    cell   = {key: mean(v) for key, v in data.items()}

    ssa  = b * n * sum((mean_A[i] - grand_mean) ** 2 for i in A_levels)
    ssb  = a * n * sum((mean_B[j] - grand_mean) ** 2 for j in B_levels)
    ssab = n * sum((cell[(i, j)] - mean_A[i] - mean_B[j] + grand_mean) ** 2
                   for i in A_levels for j in B_levels)
    sse  = sum((x - cell[key]) ** 2 for key, v in data.items() for x in v)

    df_e = a * b * (n - 1)
    mse = sse / df_e

    results = {}
    for name, ss, df in [("Factor A (fertilizer)", ssa, a - 1),
                         ("Factor B (sunlight)",   ssb, b - 1),
                         ("Interaction A x B",     ssab, (a - 1) * (b - 1))]:
        ms = ss / df
        F = ms / mse
        p_value = stats.f.sf(F, df, df_e)         # right-tailed
        results[name] = (ss, df, ms, F, p_value)
    return results, sse, df_e, mse

results, sse, df_e, mse = two_way_anova(data)

print(f"{'Source':<24}{'SS':>9}{'df':>5}{'MS':>9}{'F':>10}{'P-value':>12}")
for name, (ss, df, ms, F, p) in results.items():
    print(f"{name:<24}{ss:>9.3f}{df:>5}{ms:>9.3f}{F:>10.4f}{p:>12.6f}")
print(f"{'Error (within)':<24}{sse:>9.3f}{df_e:>5}{mse:>9.3f}")

print()
for name, (ss, df, ms, F, p) in results.items():
    verdict = "Reject H0 (significant)" if p < alpha else "Fail to reject H0 (not significant)"
    print(f"{name}: {verdict}")

# print(sm.stats.anova_lm(ols("y ~ C(A) * C(B)", df).fit(), typ=2))
```

|---|---|---|---|---|---|
| Factor A (fertilizer) | 57.867 | 2 | 28.933 | 32.1481 | 0.000000163 |

## Quick Summary

| Concept | Idea | Used For |
|---|---|---|
| F-test | Compare two sample variances using `F = s1^2 / s2^2` | Checking whether two groups are equally consistent/spread out |
| One-Way ANOVA | Compare variation between groups with variation within groups, `F = MSB / MSW` | Checking whether 3 or more group means are equal |
| Two-Way ANOVA | Split variation into Factor A, Factor B, interaction and error; one F-test for each | Studying two factors (and their interaction) on one outcome |
